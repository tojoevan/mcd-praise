# 麦麦夸我好身材 · 换算公式（透明、可调）

## 一、步行消耗（去店里吃再走回来）
```
走路消耗(kcal) ≈ 体重(kg) × 距离(km) × 系数 K
```
- 一趟（去+回）= 2 × 最近店 distance(米) / 1000 km
- 每公里消耗 = 体重 × K

| 参数 | 默认 | 说明 |
|---|---|---|
| 体重 weight | 60 kg | 用户可覆盖 |
| 系数 K | 0.75 kcal/(kg·km) | 中等步速、平地步行常用估算；60–70kg 成人约 45–53 kcal/km，取中值 |
| 步幅 | 0.75 m | 仅用于步数展示 |

> K 取值范围一般 0.5–1.0 kcal/(kg·km)，随体重、坡度、步速变化。Skill 需向用户说明 K 与体重均可调，结果仅为估算。

## 二、撸铁补救（补作业）
```
剩余(kcal) = 套餐总kcal − 走路消耗(kcal)      # 最低为 0，不为负
动作个数 = ceil(剩余 / 该动作每下消耗)
```
撸铁为无氧运动，单下消耗不大（EPOC 后续燃脂另算，本工具只算当次动作）。
下方为 **70kg 成人、自重或轻自由重量** 的粗略每下消耗估算，纯趣味演示用：

| 动作 | 每下消耗(kcal) | 备注 |
|---|---|---|
| 深蹲 squat | 0.35 | 下肢之王 |
| 硬拉 deadlift | 0.50 | 全身发力，单位消耗最高 |
| 卧推 bench press | 0.30 | 推胸 |
| 引体向上 pull-up | 0.40 | 拉背，自重为主 |
| 俯卧撑 push-up | 0.25 | 居家友好 |
| 二头弯举 curl | 0.20 | 纯点缀 |

> ⚠️ 这些数值是粗略估算，用于制造"补作业"的趣味反差；真实消耗因体重、重量、组间休息差异很大。输出务必标注"非专业运动建议"。

## 三、示例（基于 2026-10-24 上海·人民广场 真实 MCP 返回）
- 最近店 **144m** → 来回 288m，体重 60kg、K=0.75 → 走路消耗 ≈ 60 × 0.288 × 0.75 ≈ **13 kcal**
- 巨无霸三件套 **949 kcal**，剩余 = 949 − 13 = **936 kcal**
- 撸铁个数：深蹲 936/0.35 ≈ 2674 个；硬拉 936/0.5 ≈ 1872 个；卧推 936/0.3 ≈ 3120 个；引体 936/0.4 ≈ 2340 个
- 结论：**你这趟散步烧掉的热量，还不够塞巨无霸一个角的缝，剩下全靠撸铁慢慢还。**
